# Story version (archived)

This is the original choose-your-path story version of this app, kept for the record. It was replaced by a non-fiction information bank on 3 November 2026. Nothing was deleted.

- Git tag: `story-version` (the commit just before the change).
- `src/` is a copy of the story source, and `build.js` and `README.md` are copies of the files that built and described it. To rebuild the story version, copy these into a fresh clone at the tag and run `node build.js`.
- The people and events in the story are invented. See the story's "Behind the Story" page.
